## 浏览器模式：通用登录字段自适应适配（兼容非 NexusPHP 架构）
- 需求：用户要求浏览器模式登录解析兼容更多类型网站（NexusPHP 之外，如 React/Vue SPA），不要只为 pting.club 写死。原 `perform_login` 只用品类写死的 `DEFAULT_*_SELECTORS`（`input[name=username]` 等），对 SPA 完全不自适应，且无自动探测。
- 改动（通用，不针对单一站点）：
  - `utils.py` 的 `JS_FILL_TEMPLATE` / `JS_FILL_CAPTCHA_TEMPLATE`：填充改用**原生 value setter**（`Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set`）后再派发 input/change 事件，兼容 React/Vue 受控组件（直接 `el.value=` 不更新框架状态，提交拿到空值——这是 SPA 站点「能定位却登录不上」的隐藏主因）。
  - `executors/browser.py` 新增 `detect_login_fields(driver)`：导航到登录页后用 JS 启发式识别 账号/密码/提交按钮，优先用 id/name/type/autocomplete/placeholder 等稳定属性（避开 CSS-Modules/Tailwind 哈希类名）。账号按 autocomplete/name/placeholder/type 打分；提交按钮取 form 内 `button[type=submit]` 或文本含登录词的按钮（用 XPath `//button[@type='submit' and contains(.,'登录')]` 排除「登录后签到」等同页按钮）。
  - `perform_login`：用户未显式配置选择器时，导航后再跑 `detect_login_fields` 兜底，最终仍回退 `DEFAULT_*_SELECTORS`（**保证原有配置无损**）；结果判定新增「出现已登录标识(退出/logout)→成功」「命中失败词→提前返回」避免空等 30s。
  - `is_login_page` 放宽：有密码输入框即视为登录页（兼容用户名框命名为 email/phone/identity 的 SPA）。
- 验证：`node --check` 已校验探测 JS 语法；Python 无 lint 错误。实际浏览器端回归需用户在有站点时测试（pting.club 登录页字段为 `#login-identity` / `#login-password`，无验证码）。
- 修复（用户实测反馈）：初版「三个选择器都配置就跳过探测」会导致 pting.club 用默认 `input[name=username]`（实际 name=identity）而用户名填不进。改为**自愈式** `_pick_selector`：始终探测，用户配置的选择器只要在当前页面真能定位到元素就优先用，定位不到才回退探测/DEFAULT。新增 `_selector_exists` 判断选择器是否真实存在。pting.club 实测：密码 `input[name=password]` 命中直接用、用户名配置失效→自动探测 `input#login-identity` 生效。
- 注意：探测可能误选（多密码框/同页多登录类按钮），故保留用户手动 selector 优先级与 DEFAULT 兜底。
- 关键实测复现（用 DrissionPage 真连 pting.club + 假账号密码回读验证，已 PASS）：初版仍失败，根因是 **DrissionPage v4 的 `page.run_js` 只在脚本以 `return` 开头时才返回值，否则只执行副作用并返回 None**。因此：
  - `detect_login_fields` 的探测 IIFE 与 `_selector_exists` 的 IIFE 都必须以 `return` 开头，否则探测永远返回 None / `_selector_exists` 永远 False → `_pick_selector` 退化为 DEFAULT（`#username` 在 pting.club 不存在 → 用户名不填）。已加 `return`。
  - 以前用 `sel.replace("'", "\\'")` 手动转义再 `%` 拼进 JS 单引号字符串，在含单引号的值（如 XPath 中 `contains(.,'登录')`）会截断字符串。全部改用 `json.dumps(value)` 生成合法 JSON 字符串，并让模板占位符 `%s` 不带自带引号（utils.py 的 `JS_FILL_TEMPLATE`/`JS_GET_SRC_TEMPLATE`/`JS_FILL_CAPTCHA_TEMPLATE`/`JS_CLICK_TEMPLATE` 已改为 `fillElement(%s,%s)` 等）。
  - `_selector_exists` 用 `sel.split(',')` 支持多 CSS 选择器，但会把 XPath 里 `contains(normalize-space(.), '登录')` 的逗号也拆断。已改为：以 `//` 开头的 XPath 整体不拆，仅 CSS 才按逗号拆。
  - 验证结论：pting.club 现正确识别 账号=`input#login-identity`、密码=`input#login-password`、提交=`//button[@type='submit' and contains(normalize-space(.),'登录')]`，假账号密码均真填入（回读 uValue/pValue 正确）。
