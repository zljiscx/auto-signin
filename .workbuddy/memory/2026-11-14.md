# 2026-11-14

## 修复：桌面模式(CDP) 签到失败 + 站点卡死拖垮整批

### 现象
- 躺平在 desktop 模式仍失败：60 秒拿不到 Turnstile token，日志「点击0次」。
- 躺平第 2 次尝试报「连接桌面浏览器失败: 与页面的连接已断开」，随后整批卡住 4 小时，16:00 任务被跳过。

### 根因
- Turnstile 的「Verify you are human」在**跨域 iframe** 里，父文档读不到；旧的 CDP DOM 树探测恒为 unknown → 一次都不点。
- DrissionPage 4.0.4 对页面实例(`ChromiumPage._PAGES`)与浏览器连接(`Browser.BROWSERS`)做类级缓存；`disconnect()`/关标签后重连拿到的是已断开的旧对象，且可能永久阻塞。
- 带调试连接调 `GET /json/close/<id>` 会挂住（实测 5s 超时）。

### 改法
- `_handle_turnstile`：按 `.cf-turnstile` 组件坐标派发 CDP 鼠标事件点击（x+30, 垂直居中），token 为唯一判据；删除 CDP DOM 树探测的四个死函数。
- 远程连接整进程复用（`_REMOTE_DRIVERS`）：结束只把标签退回 about:blank，不再断开/关标签。
- `sign_service._run_with_timeout`：单站单次执行上限 240 秒，超时放弃并继续下一个站点。

### 实测（100.100.1.10:9222，Chrome/154 Linux）
- 坐标点击 2 秒拿到 token（773 字符）；三轮连续执行 63s/52s/55s 全部 success。
- cf_clearance 在该浏览器 profile 内复用，后两轮直接「未检测到 Cloudflare 验证」。
