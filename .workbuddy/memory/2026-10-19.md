## 接口
- `GET  /v2/activity/growth/redeem/summary` → `data.{starter,advanced,legendary}_status`
- `POST /v2/activity/growth/redeem`，body `{"tier":"7d|14d|28d","client_token":"u-<uuid>"}`
- 三档：`("7d","starter","入门",7)`、`("14d","advanced","进阶",14)`、`("28d","legendary","巅峰",28)`
- 状态语义：`claimed` 已领 / `locked` 未解锁 → 跳过；其它（如 claimable）→ 领取
- 领取响应发放字段：`credit_granted` / `energy_granted` / `cards_granted` / `chances_granted`
- `redeem` 返 403 = 连登天数不足，属业务常态不算失败；返 400 且 msg 含 `tier` = 档位标识被拒 → 退回天数重试

## 本项目实现
`executors/buddy.py` 新增：
- 常量 `ENDPOINT_GROWTH`、`GROWTH_TIERS`、`DEFAULT_GROWTH`
- 模块级 `_dig()`（兼容 data/result/resp/response 包裹）
- `_load_growth_cfg()` / `_growth_enabled()`（站点 `api_config.growth.enabled` 可关，默认开）
- `_growth_call()`（payload=None 走 GET，否则 POST；带 `X-Product: SaaS`）
- `_run_growth_once()`：独立门控，状态存 `token_store.growth_state.last_checked_date`，
  当日查询成功才写；异常不写，留待下次补做
- `_claim_growth_rewards()` / `_reward_text()`

## 三者独立门控
签到（服务端幂等 + 自身 3 次重试）、对话（`chat_state.last_chat_date`）、
领奖（`growth_state.last_checked_date`）互不影响；**签到失败时对话与领奖照常执行**。

## 推送格式
奖励行追加在【Buddy加油站今日状态】块末尾（每日登录之后），每条一行、两空格缩进：
```
【Buddy加油站今日状态】
  连续签到：N 天
  ...
  每日登录：完成（…）
  领7天档：+100 积分 +1 补登卡
```
无「领N天档」字样的是异常行：`领奖：查询失败（HTTP 500）`、`领N天档：领取失败（HTTP xxx …）`。
无可领取档位时静默，不输出任何行。
