## 修复：躺平(站点14) 浏览器模式假通过导致签到失败

- 现象：zljiscx 上日志停在「检测到 Cloudflare Turnstile 组件」→「点击后未检测到成功标识」。
- 根因：`_handle_turnstile` 超时后用「顶层 HTML 无 `Verify you are human`」判通过，但该文案在 CF 跨域 iframe 里，顶层永远读不到 → token 为空也静默 return True，拿空 token 点签到被服务端拒。
- 实测（本机）：browser 模式 30s 拿不到 token、点击 0 次；desktop 模式 token 752 字符 → 签到成功。
- 修复：Turnstile 只认 `cf-turnstile-response` token>20；点击后轮询 8s 并自动确认 alert/confirm；失败日志改打印 `body.innerText` + 截图；文案改为「Cloudflare验证未通过（建议改用桌面模式）」。
- 结论：Turnstile 站点在无头 Chrome 里过不了，只能走 desktop(CDP)；改动代码无法绕过。
