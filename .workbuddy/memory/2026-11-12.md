# 2026-11-12 躺平站点（tangpt.top）Cloudflare Turnstile 配置

## 抓包事实
- 登录：POST /takelogin.php，表单字段 `username` / `secret` / `two_step_code` / `cf-turnstile-response` / `response`（密码不在表单里，由页面 JS 算 sha256(clientHash, challenge secret) 后写入 hidden `response`）。
- 签到：POST /attendance.php，body 仅 `cf-turnstile-response`。
- 两处都要 Turnstile token，**API 模式无法实现**（token 由浏览器 JS 生成，一次性、约 5 分钟有效）。
- 站内登录页 turnstile 为 managed（不可见），实测约 14 秒自动生成 token。

## 修复的两个真实缺陷（executors/browser.py）
1. `detect_login_fields` 的 `cssOf` 兜底返回裸 `tagName`。该站密码框无 name/id/placeholder，导致密码选择器变成 `input`，会把密码填进第一个 hidden 字段 → 登录必失败。
   改为在 placeholder 之后加 `[type="xxx"]` 兜底，现在返回 `input[type="password"]`。
2. `is_login_page` / `_has_turnstile` / `_handle_turnstile` / `_wait_cloudflare` 用 `page.ele('input[name="cf-turnstile-response"]')` —— DrissionPage 4 不认这种纯 CSS 写法，永远取不到值，Turnstile 只能干等超时后"宽松放行"。
   新增 `_turnstile_token_len(driver)` 统一走 JS 读取，token 就绪立即返回（实测从等 30 秒降到约 14 秒）。
3. `click_sign_button` 自定义选择器补充 JS（querySelector）回退，支持 `input[value="立即签到"]` 这类标准 CSS；JS 兜底从只找 `.x-button` 扩展为 `.x-button, button, input[type=submit], input[type=button], a`，按文案"立即签到"精确定位。

## 该站正确配置
- 模式：浏览器模式
- 登录地址 https://www.tangpt.top/login.php，签到地址 https://www.tangpt.top/attendance.php
- **必须勾选「Cloudflare 验证」**（否则 turnstile 完全不处理）
- 建议勾选「登录优先」（先登录再进签到页）
- 签到按钮选择器可留空（JS 兜底能定位「立即签到」），或填 `input[value="立即签到"]`
- 全局 `cf_timeout` 需 ≥ 30 秒（token 生成约 14 秒）
- 数据库 id=14，原 has_cloudflare=0/login_first=0，是失效主因
